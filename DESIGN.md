# Attobrain design system

## Visual direction

Use the existing Attobrain identity shown in the Figma file `protótipo - ATTObrain`. Keep the product interface light, calm, legible, and focused on participant activity data. The learner view remains a separate, distraction-light experience.

## Tokens

- Brand violet: `#6941C6`; Figma login action violet: `#3928D8`.
- Teal: `#087F73`; login gradient end: `#16AAAD`.
- Ink: `#0F172A`; muted text: `#64748B`; border: `#E2E8F0`.
- Page: `#F6F7FB`; surface: `#FFFFFF`; pale violet: `#F5F3FF`.
- Typeface: Manrope, with system sans-serif fallback.
- Base spacing: 4px increments; cards use 16px radius; controls at least 44px high.

## Login

At desktop widths, use the Figma split composition: a 39% violet-to-teal brand panel on the left and a neutral access area on the right. Place the logo and message on the left; center a 410px access form on the right. At widths below 760px, stack the brand message above the form. Keep field labels visible, focus rings clear, errors announced, and reduced-motion preferences respected.

## Professional and learner screens

Professional screens use the branded sidebar, clear phase context, compact data panels, and restrained color for status and chart series. Keep charts labeled with units, time ranges, and explicit data quality. Missing or ineligible measurements appear as unavailable or insufficient, never as zero. The learner screen uses the original student module, its original maze colors, and no professional navigation or reports.

## Project information page

Expose academic context, task purpose, theoretical references, team, and MVP limits through the professional navigation. Reuse existing cards and typography. Keep the academic profile as version-controlled site content; it does not belong in participant or session tables. List team names only when confirmed, without inferred job titles.

## Illustrations and motion

Use the generated transparent illustrations as supportive explanations, never as measurements:

- `assets/gaze-maze-vision.png`: conceptual future gaze path; use in login, learner waiting, and conceptual empty states. Hide it while the participant is navigating the active maze.
- `assets/future-sensor-concept.png`: future sensor integration concept for the professional overview. Pair it with a clear status that sensors are not connected.
- `assets/visual-focus-concept.png`: conceptual visual-focus layer and empty chart state. It is not an attention score or session data.
- `assets/neural-signal-concept.png`: illustrative future signal layer and advanced synthetic-signal panel. State that the current waveform is generated by software.
- `assets/attention-network-art.png`: conceptual cortex illustration paired with the educational attention-network guide. It is not a scan, source map, or participant reading.
- `assets/explainable-results-concept.png`: report structure/source-of-data explanation and insufficient-evidence state; it never stands for actual results.
- Existing report and connection illustrations remain decorative, use empty alt text, and stay out of print output.

Gaze, focus, and neural illustrations are allowed only as visibly labeled concepts or simulations; never show them as live participant readings. The current trajectory uses a temporary pointer input as a development proxy, not eye tracking; EEG is synthetic. Keep chart marks sourced from actual session records and label units and eligibility separately.

The attention guide separates the literature's dorsal and ventral attention networks from example scalp electrode positions in the 10–20 system. Scalp electrode names describe surface locations; do not imply a one-to-one mapping from an electrode to a cortical source. The guide is educational only, the MVP does not estimate attention, and source-localization limits must remain visible.

Use short one-shot transitions and a very slow decorative float on concept art only. Do not animate active maze paths, chart data, or sensor states in a way that could be mistaken for a real reading. Respect `prefers-reduced-motion`; decorative illustrations use intrinsic dimensions to avoid layout shifts and are lazy-loaded when below the fold.

## Interaction and responsive behavior

Use visible focus, semantic headings and labels, 44px minimum action targets, and concise inline errors. Support 320px and wider without horizontal page scrolling. Disable animations and transitions under `prefers-reduced-motion: reduce`.
