# Attobrain

Protótipo de front-end do fluxo mínimo demonstrativo do Attobrain. O projeto usa HTML, CSS, JavaScript e o servidor HTTP nativo do Node.js; não precisa instalar dependências.

## Executar

```bash
npm start
```

Abra [http://localhost:3000](http://localhost:3000). Os cadastros ficam no `localStorage` do navegador. O labirinto, os gráficos e os resultados usam dados sintéticos; o protótipo não conecta sensores, não mede atenção e não faz diagnóstico.
